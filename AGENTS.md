# Routage des skills GML

Charger uniquement la skill correspondant à la tâche :

- dataset, import, nettoyage ou transformation : `.agents/skills/gml-data-ingestion/SKILL.md`
- nouvelle feature, nouvelle colonne C2D, métadonnée ou document source : `.agents/skills/gml-feature-leakage-audit/SKILL.md`
- split, historique, preprocessing, cross-validation ou évaluation temporelle : `.agents/skills/gml-temporal-validation/SKILL.md`
- entraînement, comparaison de modèles, métriques ou résultats : `.agents/skills/gml-model-evaluation/SKILL.md`
- nouvelle expérience, feature, transformation ou modèle à tester : `.agents/skills/gml-experiment-workflow/SKILL.md`
- grosse PR, fin d’itération, release ou rendu : `.agents/skills/gml-deliverable-check/SKILL.md`

Les skills peuvent être combinées si la tâche recouvre plusieurs déclencheurs. Ne pas charger les six par défaut.
