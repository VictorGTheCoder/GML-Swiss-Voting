# Typologies territoriales et régions linguistiques

`commune_typologies.parquet` : une ligne par commune, avec les classifications
territoriales et linguistiques et leurs libellés. `municipality_id` est une chaîne
OFS sur quatre caractères compatible avec les votations. `commune_code` est conservé.

Table statique à l'état communal du 01.01.2026. La date de publication des
classifications n'est pas vérifiée : ne pas en déduire une disponibilité historique.

Voir [la documentation des typologies](../../../docs/datasets/typologies/README.md).
